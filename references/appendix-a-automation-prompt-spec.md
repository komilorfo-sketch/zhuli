# 附录 A · 定时任务提示词生成要求（按访谈结果现场生成）

> 参数定义：`<知识库>`＝知识库文件夹路径，`<助理名>`＝助理名，`<推送方式>`＝访谈确认结果（WorkBuddy 端推送 / 只存档案等用户来问），`<目标>`＝用户在访谈 C8 定的目标（**无在追目标时，打卡一问整行改为"今天没有在追的目标"**）。
> 定时任务在**新会话**中执行，**什么都不知道**——所以每条提示词必须**自包含**：路径、身份、流程全写明。以下为生成要求清单，构建 AI 据此为用户现场生成各条提示词。

**每条简报提示词的生成清单（逐条核对，缺一不可）**：

1. **身份与路径**：开头声明加载 `<助理名>` SKILL、知识库在 `<知识库>`；兜底——若执行环境不认识"加载 SKILL"惯例，改为"先读助理 SKILL 文件并按其执行"；
2. **数据来源**：写明读 `<知识库>\60-秘书系统\` 下哪些核心文件（待办池/日程表/承诺跟踪/追踪日志/_目标看板）；
3. **输出结构按简报类型区分**：
   - 晨报＝今日日程+到期事项 ≤10行 + 末尾固定一行目标打卡一问（回复即更新 _目标看板）；
   - 提醒扫描＝扫全表找今日到期项 ≤10行；
   - 晚报＝置顶"待你决策"区+今日完成/明日安排/到期承诺+今日入库 N 条清单 ≤10行 + **末尾固定一行系统自检**（入库/归档/简报/定时任务漏跑，全正常只写"系统自检：正常"，异常标⚠️）；
   - 周报＝各板块各一小节+本周收集与所学+目标打卡统计+承诺兑现+僵尸待办点名（超14天）+下周计划 + **末尾一行收尾自检**（扫收件口与微信临时目录残留）；
   - 月报＝月度回顾+目标进度+系统健康栏（定时任务近况/Inbox 残留/知识库文件数）+ zip 全知识库至 `_备份\`（保留12份）；
4. **落盘与推送**：写明存入 `<知识库>\60-秘书系统\简报\`、推送方式为 `<推送方式>`；
5. 提示词是给 AI 执行的，不需要用户看懂；替换参数后路径不得再删。

**时间表参考**：晨报 7:30／提醒扫描 8:00／晚报 21:30／周报周日 20:00／月报每月 1 日 9:00；收尾兜底（可选，每日 21:00）：扫 `00-Inbox` 与微信临时目录，有残留逐条归档（原文移 `90-归档\<分类>\`（分类直接挂 90-归档 下，无"原始文档"中间层），禁止删除；不合格/弃用的产物不进归档，直接删除）并更新追踪日志，无残留报"今日无残留"。⚠️ 一条定时任务一天只能一个时间点，一天多时间点必须拆成多条。
