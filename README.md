# 打造你的全能私人助理 · zhuli

> 20 分钟对话，把 WorkBuddy + 微信变成你的**全能私人秘书**——AI 包办施工，你全程只出嘴。所有资料归档在**你自己的电脑**上，不进任何云端。

---

## 它能帮你做什么

| 你随口一句 / 随手一转 | 助理自动完成 |
|---|---|
| 转发一篇好文章、一个文档到微信 | 变成知识卡入库，**原件永久保留在你电脑上** |
| "下周三提醒我给客户发方案" | 自动进日程，到点答复 |
| "我答应过周五给老李报价" | 进承诺跟踪表，**到期前一天主动提醒** |
| "帮我做 XX 方案" | 办事之前，先主动列出你档案柜里的可用资料供你参考 |
| 转发一个视频链接 / 一个视频文件 | 自动转写成**逐字稿＋学习总结**（抖音/B站/头条/微信转发的视频都行），总结入库沉淀、原件保留 |
| 每周日 20:00 | 知识看板自动生成：本周进了什么、各板块长了多少，双击网页就能看自己的知识库长大 |
| 每天 21:30 | 晚报自动汇报：今天办了什么、进了多少资料、明天有什么要紧事，末尾一行系统自检，一切正常只报"正常"三个字 |

**数据 100% 归你**：所有对话、资料、文档统一从微信一个入口进来，全部存在你本机的知识库文件夹——不传第三方云盘、不存别人服务器，断网也不丢。

## 三类活，三种接法（助理自己判断，你不用记）

- **零散事** → 直接办（日程、待办、随手记、找文件）
- **有套路的活** → 调技能办（周报月报、台账、固定格式文档）；没有现成技能时会问你要说法还是现场建一个
- **专业的事** → 请专家办（法律、税务、健康等），把关权永远在你

越用越强：同类活做满三次，它会主动建议固化成你的专属技能。

## 8 步搭建流程（对话引导，AI 施工）

①聊聊你的情况 → ②把你要管的几摊事定好规矩 → ③讲清架构＋连上微信 → ④搭好档案柜 → ⑤微信全链路实测＋定时简报＋喂进你已有的资料 → ⑥补齐人脉、目标等细节 → ⑦试运行一周（系统每日自检）→ ⑧交付你的专属《操作手册》

全程你只做两个动作：**随手转、随口说。**

## 适合谁用

- 想要"记得住、找得到、会提醒"的私人助理，又不想折腾配置的人
- 在意数据隐私、希望资料存在自己电脑而非云端的人
- 微信重度用户：所有事都从微信说，不用学任何新软件
- 爱看视频学习、不想让收藏夹吃灰的人（视频链接/文件甩进微信，自动变成文字稿和学习笔记）

## 技能升级

技能发布新版本后，WorkBuddy 会自动检测并升级到最新版；若技能页出现红点提示，点击更新即可。升级不会影响你已建的知识库和档案柜——那些都在你自己的文件夹里，和技能版本无关。
